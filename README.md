# 📱 BMO Organizer PWA

Desktop-first PWA para organização pessoal, calendário de rotina (integrado ao WhatsApp via Evolution API) e Kanban de projetos com agentes de IA autônomos no Homelab BMO.

## 🚀 Tecnologias
- Vue 3 + TypeScript
- Vite + Tailwind CSS v4
- Pinia + Vue Router
- Lucide Icons + Axios

## 🛠️ Comandos
```bash
npm install
npm run dev
npm run build
```
